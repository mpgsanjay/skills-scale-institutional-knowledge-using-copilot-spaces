## Overview

OctoAcme follows a structured yet flexible project management approach designed to deliver customer value through iterative delivery, clear ownership, and data-informed decisions.

### Core Principles

OctoAcme's project management is built on these foundational principles:

- **Customer-first**: Prioritize customer value and usability in every decision
- **Iterative delivery**: Deliver small, testable increments for faster feedback
- **Clear ownership**: Each project has named Project Manager (PM) and Product Lead for accountability
- **Data-informed decisions**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback, collaboration, and continuous learning

### Key Roles

Our projects are structured around clear role definition:

- **Project Manager (PM)**: Coordinates delivery, manages schedules, identifies risks, and drives communications
- **Product Manager (PdM)**: Defines outcomes, prioritizes the backlog, and measures success
- **Developers**: Implement features, collaborate on design and testability
- **QA/Testing**: Validate quality and acceptance criteria
- **Stakeholders**: Provide inputs, feedback, and approvals

### Core Artifacts

Each project maintains these key artifacts:

- Project Charter / One-pager
- Roadmap and Release Plan
- Sprint/Iteration Backlog
- Acceptance Criteria & Definition of Done
- Risk Register
- Retrospective notes and action items

## Project Lifecycle

OctoAcme projects follow a five-phase lifecycle. Each phase has dedicated documentation:

### 1. Project Initiation
**Purpose**: Validate business need, align stakeholders, and authorize work

📄 **Full Guide**: [OctoAcme — Project Initiation Guide](./octoacme-project-initiation.md)

**Key Deliverables**:
- Project One-pager (Problem, Goal, Success Metrics)
- Stakeholder list & communication plan
- High-level timeline and key milestones
- Initial risk list and resource needs

**What's Included**: Templates, initiation checklist, decision gates, and minimum deliverables for kicking off new initiatives.

---

### 2. Project Planning
**Purpose**: Turn approved initiatives into actionable plans and prioritized backlogs

📄 **Full Guide**: [OctoAcme — Project Planning](./octoacme-project-planning.md)

**Key Activities**:
- Kickoff meeting with stakeholders and delivery team
- Create prioritized backlog with acceptance criteria
- Estimate scope using T-shirt sizing or story points
- Define Definition of Done (DoD)
- Identify dependencies and integration points
- Create release plan and milestone map

**What's Included**: Backlog item templates, sprint planning guidance, risk and dependency management, and planning checklists.

---

### 3. Execution & Tracking
**Purpose**: Manage day-to-day execution and track progress toward milestones

📄 **Full Guide**: [OctoAcme — Execution & Tracking](./octoacme-execution-and-tracking.md)

**Key Activities**:
- Daily standups and weekly delivery syncs
- Project board management (Backlog → Ready → In Progress → In Review → QA → Done)
- Pull request workflow and code review process
- Quality assurance and testing
- Progress reporting and metrics

**What's Included**: Team rhythm guidelines, workflow standards, quality requirements, blocker escalation process, and execution checklist.

---

### 4. Release & Deployment
**Purpose**: Deploy verified work to production safely and communicate releases

📄 **Full Guide**: [OctoAcme — Release and Deployment](./octoacme-release-and-deployment.md)

**Key Activities**:
- Pre-release checklist and verification
- Deployment planning and rollout strategy
- Release communication and announcements
- Post-deployment monitoring and support
- Success metrics validation

**What's Included**: Release readiness criteria, deployment procedures, communication templates, and rollback procedures.

---

### 5. Retrospective & Continuous Improvement
**Purpose**: Capture learnings, celebrate successes, and plan improvements

📄 **Full Guide**: [OctoAcme — Retrospective and Continuous Improvement](./octoacme-retrospective-and-continuous-improvement.md)

**Key Activities**:
- Conduct project retrospective (what went well, what could improve)
- Document lessons learned and action items
- Update playbooks and processes based on learnings
- Plan next steps and related initiatives

**What's Included**: Retrospective format, action item tracking, process improvement guidelines, and knowledge capture methods.

## Communication Cadence

OctoAcme maintains consistent communication to keep teams aligned:

- **Daily**: 15-minute standups (focus on progress, blockers, dependencies)
- **Weekly**: PM + PdM sync; Twice-weekly delivery team standups (or as agreed)
- **Monthly**: Stakeholder updates and progress reviews
- **Ad-hoc**: Escalations for critical issues and blockers
